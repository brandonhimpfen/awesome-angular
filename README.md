## Official Resources

- [Angular Documentation](https://angular.dev/) – Official docs for Angular.
- [Angular GitHub](https://github.com/angular/angular) – Source code for Angular.
- [Angular CLI](https://github.com/angular/angular-cli) – Official command-line tooling.
- [Angular Examples](https://github.com/angular/angular/tree/main/aio/content/examples) – Official code examples.
- [Angular DevTools](https://github.com/angular/angular/tree/main/packages/angular_devtools) – Debugging and profiling tools.

## Starter Kits & Templates

- [Angular QuickStart](https://github.com/angular/quickstart) – Official starter template.
- [Angular Enterprise Starter Kit](https://github.com/tomastrajan/angular-ngrx-material-starter) – Enterprise-ready starter using NgRx & Material.
- [Nx Angular Workspace](https://nx.dev/) – Monorepo toolkit supporting Angular.
- [ASP.NET Core + Angular Template](https://github.com/dotnet/aspnetcore) – Full-stack example template.
- [Scully Starter](https://github.com/scullyio/scully) – Static-site generation for Angular.

## UI Libraries & Components

- [Angular Material](https://github.com/angular/components) – Official Material Design UI components.
- [PrimeNG](https://github.com/primefaces/primeng) – Large, polished UI component suite.
- [NG-ZORRO](https://github.com/NG-ZORRO/ng-zorro-antd) – Ant Design components for Angular.
- [Nebular](https://github.com/akveo/nebular) – Customizable UI library for admin dashboards.
- [Clarity](https://github.com/vmware/clarity) – Angular components from VMware.
- [ngx-bootstrap](https://github.com/valor-software/ngx-bootstrap) – Bootstrap components for Angular.

## State Management

- [NgRx](https://github.com/ngrx/platform) – Redux-inspired state management for Angular.
- [Akita](https://github.com/salesforce/akita) – Entity-based state management.
- [NGXS](https://github.com/ngxs/store) – Simple, decorator-based state library.
- [RxJS](https://github.com/ReactiveX/rxjs) – Core reactive programming library used widely in Angular.

## Utilities & Development Tools

- [Angular ESLint](https://github.com/angular-eslint/angular-eslint) – Official Angular linting support.
- [Prettier + Angular Plugin](https://github.com/prettier/prettier) – Code formatting support.
- [Angular CDK](https://github.com/angular/components/tree/main/src/cdk) – Component Dev Kit for accessibility & utilities.
- [Compodoc](https://github.com/compodoc/compodoc) – Documentation generator for Angular apps.
- [Storybook for Angular](https://github.com/storybookjs/storybook) – UI component development environment.

## Testing

- [Jasmine](https://github.com/jasmine/jasmine) – Behavior-driven testing framework used by Angular.
- [Karma](https://github.com/karma-runner/karma) – JavaScript test runner used in Angular CLI.
- [Jest](https://github.com/jestjs/jest) – Popular testing framework with Angular presets.
- [Cypress](https://github.com/cypress-io/cypress) – End-to-end testing for Angular apps.
- [Playwright](https://github.com/microsoft/playwright) – Cross-browser E2E framework.

## SSR, SSG & Performance

- [Angular Universal](https://github.com/angular/universal) – Server-side rendering for Angular.
- [Scully](https://github.com/scullyio/scully) – Static site generator for Angular.
- [ngx-build-plus](https://github.com/manfredsteyer/ngx-build-plus) – Extend the Angular build process.
- [Nitro + Angular Integrations](https://nitro.unjs.io/) – Lightweight server engine for Angular SSR.
- [Angular DevTools](https://github.com/angular/angular/tree/main/packages/angular_devtools) – Performance and profiling suite.

## Learning Resources

- [Ultimate Courses – Angular](https://ultimatecourses.com/angular) – Premium Angular learning.
- [Fireship Angular Videos](https://www.youtube.com/c/Fireship) – Short, high-impact Angular videos.
- [Academind Angular Courses](https://academind.com/) – Beginner and intermediate tutorials.
- [Official Angular Blog](https://blog.angular.io/) – Updates and best practices.
- [RxJS Documentation](https://rxjs.dev/) – Essential for understanding Angular’s reactive architecture.
